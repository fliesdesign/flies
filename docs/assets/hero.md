# README hero

`hero.png` — 1600 × 900, 8-bit grayscale. Generated with the built-in image generation tool
through `codex exec`, then converted to grayscale and downscaled with ImageMagick.

Same palette and pixel-grid language as [`design/branding`](../../design/branding):
charcoal `#181818`, panels `#222222`, recessed `#101010`, near-white `#ECECEC`,
silver `#C8C8C8`, mid-gray `#8E8E8E`.

## Generation prompt

Use case: repository README hero banner for "Flies", a professional design canvas application
with a dark, neutral, developer-tool aesthetic. Style reference:
`design/branding/flies-pixel-fly-v1.png` (palette and geometry only).

A wide cinematic banner depicting an abstract, stylized design-tool canvas rendered as flat
vector geometry. The scene reads as a dark editor workspace seen head-on: a faint fine dot grid
across the full background, a few large empty rounded rectangles that suggest artboards and
frames floating at different depths, thin hairline alignment guides crossing between them, and
small square selection handles on the corners of one frame. On the left edge and the right edge,
slim vertical panel columns as simple flat bars with short abstract rows, no readable interface
text. The brand mark — an original coarse pixel-art fly built from large square steps with two
broad stepped wings and a short compact body — sits in the upper-left third as a placed object
on the canvas with its own thin selection outline.

Composition: 16:9 landscape, generous negative space, elements aligned to a strict horizontal
and vertical grid. Flat vector graphic design, no 3D, no perspective, no gradients, textures,
shadows or glow. Strictly monochrome grayscale. Exact text: the single word FLIES in uppercase,
wide letterspacing, near-white, to the right of the mark; no other lettering or glyphs.

## Refinement pass

Edit of the first render, preserving framing, lettering, panels, artboards, handles, guides and
grid: redraw only the pixel mark so it matches the branding reference — two broad stepped wings
flaring outward and slightly upward in large square stair steps, short compact central body,
small square head, two tiny square antennae, near-symmetrical, all edges horizontal or vertical,
flat `#ECECEC` with one silver `#C8C8C8` lower wing band, no blobby or merged shapes.
